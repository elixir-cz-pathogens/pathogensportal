## Update date

Every dashboard states how current its data are. Depending on the data, it shows one of these:

| Label | Meaning |
|---|---|
| **Updated: 16 Oct 2026, 05:56 UTC** | When the portal last processed data from the source. It does not say which period the data cover. |
| **Data through 13 Sep 2026 (week 37/26)** | The last day or calendar week the data cover. |
| **Data through 12/2025** | The last month the data cover. |
| **Data for 2025** | The data are annual; the last available year is shown. |

The date is always read from the data file itself, not from when the page was last edited.

Processing can run today and still contain data for an older period. For example, the open ISIN
data export currently ends in December 2025, so [Signals](/en/signals/) evaluate December 2025 even
though the "Updated" date is more recent. How often each source changes is summarised on the page
[Data freshness](/en/docs/readers/data-freshness/).

## Data origin

Every dashboard carries a badge with the origin of its data: **Public source**, **Own analysis** or
**AI-assisted**. The badges are explained on the [About](/en/about/#where-the-data-comes-from) page.

## Absolute counts and rates per population

The note under every chart says whether it shows **absolute counts** or a **rate per 100,000
population** (incidence). To compare regions or periods with populations of different size, use
the rates; absolute counts mostly reflect the size of the population. More on reading the data is
on the page [Interpreting the data](/en/docs/readers/interpreting-the-data/).

## Table and exact values

The **Table** button under a chart shows the values the chart is drawn from. Hover over a point or
a region with the mouse, or tap it on a phone, to see its exact value. The downloadable data files
are described on the page [Downloads and licences](/en/docs/readers/downloads-and-licences/).

## Icons on cards

| Icon | Where | Meaning |
|---|---|---|
| <i class="bi bi-robot"></i> | top right | the content was prepared with the help of AI and reviewed by an expert |
| <i class="bi bi-box-arrow-up-right"></i> | top right | the dashboard opens on another website |
| ✦ AI | bottom right | the illustration was generated by AI (this concerns the picture, not the data) |
