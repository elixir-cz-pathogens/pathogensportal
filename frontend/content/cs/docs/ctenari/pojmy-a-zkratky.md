## Ukazatele a metody

| Pojem | Vysvětlení |
|---|---|
| **ARI**, akutní respirační infekce | Klinická diagnóza: náhlý začátek a alespoň jeden respirační příznak (kašel, bolest v krku, dušnost, rýma). Zahrnuje infekce způsobené různými viry, není laboratorně potvrzená. |
| **ILI**, onemocnění podobné chřipce | Klinická diagnóza podle definice EU: náhlý začátek, alespoň jeden celkový příznak (horečka, malátnost, bolest hlavy, bolest svalů) a alespoň jeden respirační příznak (kašel, bolest v krku, dušnost). ILI je podmnožinou ARI. |
| **Hlášený případ** | Případ nahlášený do systému povinného hlášení. Počet hlášených případů je obvykle nižší než skutečný počet nakažených a závisí na testování a na tom, zda nemocní vyhledají lékaře. |
| **Laboratorní záchyt** | Pozitivní výsledek laboratorního vyšetření vzorku na daný patogen. Počet záchytů závisí na počtu vyšetřených vzorků. |
| **Pozitivita** | Podíl pozitivních výsledků mezi vyšetřenými vzorky, v procentech. Na objemu testování závisí méně než počet záchytů. |
| **Incidence na 100 000 obyvatel** | Počet nových případů za období přepočtený na 100 000 obyvatel. Jmenovatelem je počet obyvatel podle ČSÚ. |
| **7denní incidence** | Počet nových případů za posledních 7 dní na 100 000 obyvatel. |
| **CFR**, smrtnost mezi potvrzenými případy | Podíl zemřelých mezi potvrzenými případy. Při slabém testování je nadhodnocená. |
| **IFR**, smrtnost infekce | Podíl zemřelých mezi všemi nakaženými, včetně nezachycených. Je nižší než CFR. |
| **Kalendářní týden (KT)** | Týden podle normy ISO 8601, od pondělí do neděle. Týden 1 obsahuje první čtvrtek roku. Zápis „KT 36/26“ znamená 36. týden roku 2026. |
| **Chřipková sezóna** | Období od 40. kalendářního týdne (přelom září a října) do 20. týdne následujícího roku (polovina května). |
| **MEM**, Moving Epidemic Method | Metoda výpočtu epidemického prahu a pásem intenzity z historických sezón. Používají ji ECDC a WHO. |
| **Epidemický práh** | Hodnota, nad kterou se týden považuje za epidemický. Na portálu jde o výsledek metody MEM, ne o úřední hranici pro vyhlášení epidemie. |
| **Pásma intenzity** | Nízká, střední, vysoká a velmi vysoká intenzita sezóny. Hranice se odvozují z vrcholů minulých epidemií (40., 90. a 97,5. percentil). |
| **Očekávaná (endemická) hladina** | Počet případů, který model očekává pro danou nemoc, kraj a měsíc na základě historie a sezónnosti. |
| **Signál** | Měsíc, ve kterém hlášený počet případů překročil horní mez běžného kolísání (99. percentil predikčního intervalu). Signál není potvrzením epidemie. |
| **Skóre překročení** | (nahlášeno − očekávání) / (mez − očekávání). Hodnota 1 znamená počet právě na mezi. |
| **WIS**, weighted interval score | Metrika přesnosti pravděpodobnostních předpovědí. Penalizuje široké intervaly i hodnoty mimo interval; nižší hodnota je lepší. |
| **Kvantil** | Hodnota, pod kterou leží daný podíl rozdělení (např. medián je 50% kvantil). |
| **Fylogenetický strom** | Diagram příbuznosti sekvencí patogenu. Ukazuje, jak se varianty vyvíjely a šířily. |
| **Antigenní drift** | Postupné změny povrchových antigenů viru (u chřipky hemaglutininu a neuraminidázy), kvůli kterým se každoročně aktualizuje složení vakcíny. |
| **Sledování odpadních vod (WBE)** | Sledování genetického materiálu patogenů v odpadních vodách z čistíren. Ukazatel cirkulace patogenu v populaci, který nezávisí na testování jednotlivců. |

## Zdroje dat a instituce

| Zkratka | Význam |
|---|---|
| **ISIN** | Informační systém infekčních nemocí: celostátní systém povinného hlášení infekčních nemocí podle zákona č. 258/2000 Sb., spravuje ho ÚZIS ČR. |
| **MKN-10** | Mezinárodní klasifikace nemocí, 10. revize (anglicky ICD-10). |
| **ÚZIS ČR** | Ústav zdravotnických informací a statistiky ČR. |
| **SZÚ** | Státní zdravotní ústav. |
| **NRL** | Národní referenční laboratoř; zde NRL pro chřipku a nechřipková respirační virová onemocnění při SZÚ. |
| **MZČR** | Ministerstvo zdravotnictví ČR. |
| **KHS** | Krajská hygienická stanice. |
| **ČSÚ** | Český statistický úřad (zdroj počtu obyvatel). |
| **ECDC** | Evropské středisko pro prevenci a kontrolu nemocí. |
| **ERVISS** | European Respiratory Virus Surveillance Summary: společná respirační surveillance ECDC a WHO pro Evropu. |
| **WHO FluNet / FluID** | Globální databáze WHO pro virologická (FluNet) a epidemiologická (FluID) data o chřipce. |
| **RespiCast** | Evropská platforma pro předpovědi respiračních onemocnění (ECDC). |
| **GISAID** | Databáze pro sdílení sekvencí virů chřipky a SARS-CoV-2. |
| **NUTS 3** | Statistická územní jednotka; v ČR odpovídá krajům. |
