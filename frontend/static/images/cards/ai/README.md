# AI-generated card illustrations

Put AI-generated dashboard illustrations here, and nowhere else.

The path is the label: any image under `/images/cards/ai/` renders an "AI" badge in
the corner of its card. There is no flag to set and none to forget — saving the
file here is what marks it, and moving it out is the only way to unmark it.

Reference it from a dashboard's front matter as usual:

    image: "/images/cards/ai/wastewater.webp"

Size 400×220 (any 20:11 ratio works — the card fixes the aspect and scales).
WebP or PNG, kept small: these load on the homepage.

The badge says the PICTURE was generated. Whether the page's CONTENT was written
by an AI is a separate claim, carried by `origin: ai-assisted`.
