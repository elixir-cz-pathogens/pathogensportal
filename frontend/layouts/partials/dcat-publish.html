{{- /* DCAT-AP-CZ open data catalogue — /dcat/katalog.jsonld + dataset files. Usage: {{ partial "dcat-publish.html" . }} (once per build, see below) Prints nothing; only writes files to public/. What it is: a machine-readable catalogue following the Czech open formal standard "Open data catalogue interface" (ofn.gov.cz). The same kind of description as the schema.org/Dataset in dashboard heads, but in the vocabulary understood by the National Open Data Catalogue (NKOD) and the European data.europa.eu. Called from the source-catalogue layout (single.sources.json), in the default language only. It is a trigger, not that page's output: files are written via resources.Publish to fixed paths, so the catalogue URL does not depend on where the triggering page lives. If "Data and citation" moves, the URL registered in NKOD stays valid. File-based variant of the interface, i.e. without a SPARQL endpoint: /dcat/katalog.jsonld index — points to each dataset URL /dcat/datova-sada/.jsonld full dataset record with distributions The harvester starts at the catalogue and follows links, so each dataset needs its own IRI and its own document rather than being nested in the index. The catalogue describes ONLY data the portal itself produces (data/dcat.yaml). Republished datasets are already in NKOD from their originators; duplicating them would claim an origin we do not have. Before registering in NKOD, `params.dcat.publisher` must be set — the body's IRI in the Register of Rights and Obligations. Without it the catalogue is still generated (as plain DCAT, usable outside NKOD), but harvesting rejects it because `poskytovatel` is mandatory. Registration itself is done via the data box, not in this repository. There is one catalogue for the portal; multilinguality is carried inside the values (`{"cs": …, "en": …}`), not by duplicating documents. */ -}} {{- $cfg := .Site.Params.dcat | default dict -}} {{- $base := .Site.Home.Permalink | strings.TrimSuffix "/" -}} {{- /* ── Shared parts ──────────────────────────────────────────────────── */ -}} {{- $kontakt := dict "typ" "Organizace" "jméno" (dict "cs" .Site.Title "en" .Site.Title) "e-mail" (printf "mailto:%s" (.Site.Params.mail | default "")) -}} {{- /* Terms of use in DCAT-AP-CZ have four independent axes, not one licence.
