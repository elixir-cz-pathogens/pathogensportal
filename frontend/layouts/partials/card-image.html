{{/* Dashboard card image. Returns a dict `src` + `ai`, renders nothing. Usage: {{ $img := partial "card-image.html" $page }} {{ if $img.ai }}…mark…{{ end }} Order: front matter `image` → derived from URL → placeholder. Derivation from the URL is deliberate. The Ebola pages are AI-authored and regenerated wholesale, so anything added to their front matter can be lost on the next regeneration. A derivation in the template cannot be overwritten that way. The placeholder is treated as a MISSING image, not a choice. Some pages carry it in front matter; honouring it would leave them without their topic image. ── What `ai` means ────────────────────────────────────────────────────── The PATH decides: an image under {{ "/images/cards/ai/" }} is AI-generated. Not a front matter flag — that can be forgotten, removed or overwritten by regeneration. The path is a property of the file: storing an image in that directory marks it in the same act, and the only way to unmark it is to move the file. This is NOT the same as `origin: ai-assisted`. That says AI wrote the page CONTENT; this says AI generated the IMAGE. A dashboard with human-written text and a generated illustration is the latter, not the former — conflating them would make a false claim about the data. */}} {{ $placeholder := "/images/dashboard-placeholder.svg" }} {{ $aiDir := "/images/cards/ai/" }} {{ $img := .Params.image | default "" }} {{ if or (eq $img "") (eq $img $placeholder) }} {{/* The key is the URL, not the file name: .File is nil for generated pages. */}} {{ $url := .RelPermalink }} {{ range $needle, $file := (dict "ebola" "ebola.webp") }} {{ if in $url $needle }}{{ $img = printf "/images/cards/%s" $file }}{{ end }} {{ end }} {{ end }} {{ $src := cond (eq $img "") $placeholder $img }} {{ return (dict "src" $src "ai" (hasPrefix $src $aiDir)) }}
